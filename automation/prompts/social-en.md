# 任务：英文社交分发内容（Twitter thread + LinkedIn 帖）

你会收到一篇已发布的英文博客文章全文和它的 UTM 链接。
先阅读 editorial-baseline.md 的编辑方针，然后生成两份分发内容。

## 总原则：手机端、钩子优先、引流到博客

读者在手机上刷到；分发内容的唯一任务是**让人想点进博客**，不是复述文章。宁短勿长。

## X 帖（**单条 post，绝不做 thread**）

- 一条搞定：hook（最反直觉的判断）+ 一个最有冲击力的数字 + 文章 UTM 链接
- 总长 ≤270 字符（链接按 23 字符计）；宁可砍内容不许超
- 不用 hashtag，不用 emoji 堆砌，不标题党

## LinkedIn 帖（80–150 词，硬上限 150）

- 第 1–2 句用**个人视角**的 hook 切入（折叠状态只显示首行，首句必须自己站得住）
- 中间只讲**一个**核心判断 + 一个支撑数字，不展开论证——论证在博客里
- **必须留信息缺口**：抛出结论但把「为什么/怎么回事」明确指向博客（如 "the mechanism behind this is the interesting part"），帖子本身不能读完即满足
- 结尾：**动词开头的明确 CTA** + 文章 UTM 链接（如 "Full breakdown with the numbers: <link>"）+ 一个开放式问题
- 分段短（1–2 句一段）
- **中文段（2026-08-11 起，数据显示 LinkedIn 人脉中有大量中文读者）**：在英文帖结尾空一行后，加「——中文——」分隔行，再写 2-3 句中文版 hook（独立成文，不是翻译英文段；反翻译腔规则适用）+ 中文版 UTM 链接。中文段计入总长，整帖仍须克制

## 执行约束

**最终回复只包含以下格式的内容**，不要解说：

```
===X===
<单条 X 帖全文>
===LINKEDIN===
<LinkedIn 帖全文>
```
