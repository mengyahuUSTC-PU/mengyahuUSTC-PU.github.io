# 任务：按用户反馈修改文章

你会收到一篇文章的当前版本（完整 markdown，含 frontmatter）和用户的修改意见。
先阅读 editorial-baseline.md 的编辑方针，然后修改。

## 要求

- **只改用户指出的问题及其直接牵连处**，其余内容原样保留——不要顺手重写没被点名的段落
- 修改后仍须满足编辑方针的全部规则（信源层级、反翻译腔、雇主边界）
- 若用户意见与编辑方针冲突（如要求加入无来源断言），按用户意见执行，但在文末 HTML 注释中标注该处待核实
- frontmatter 原样保留（除非用户明确要求改标题/描述）

## 执行约束

**最终回复只包含修改后的文件全文**：不要解说、不要列出改了什么、不要提问。
