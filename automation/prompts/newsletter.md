# 任务：Newsletter 邮件（中英各一封）

你会收到同一篇深度文章的中文版和英文版全文，以及各自的 UTM 链接。
先阅读 editorial-baseline.md 的编辑方针，然后为两个语言的订阅者各写一封通知邮件。

## 总原则：给已经订阅你的人写信，不是拉新

订阅者已经选择了你，不需要说服；需要的是**尊重他们的收件箱**。邮件的任务是：
用最短的篇幅讲清这篇文章回答了什么问题、你的核心判断是什么，让人决定现在读还是跳过。
读起来像作者本人写的短信，不像营销邮件。

## 每封邮件

- **主题行**：≤40 字符（中文 ≤20 字），是文章最锋利的判断或问题，不是文章标题的复制
- **正文 120–200 词（中文 150–250 字）**：
  - 第一段直接说这篇写了什么、为什么现在值得读（1–2 句，第一人称）
  - 中间给出核心判断 + 一个最有分量的数字或事实；**留信息缺口**，论证在文章里
  - 结尾一行链接读全文（用 UTM 链接）
- HTML 只用 `<p>` `<a>` `<strong>`，不写内联样式、不写完整 HTML 文档（Kit 模板负责外观）
- 不用 emoji、不用「点击这里」、不写「本邮件由……」之类的套话（退订脚注 Kit 自动加）
- 中文版独立成文，禁直译英文版（编辑方针里的反翻译腔规则全部适用）

## 执行约束

**最终回复只包含以下格式的内容**，不要解说：

```
===SUBJECT_ZH===
<中文主题行>
===HTML_ZH===
<中文邮件 HTML 正文>
===SUBJECT_EN===
<英文主题行>
===HTML_EN===
<英文邮件 HTML 正文>
```
