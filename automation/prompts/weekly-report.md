# 任务：每周运营周报

你会收到：①本周 GA4 + Search Console 数据 JSON；②上一期周报全文（若存在）；③本周发布的文章列表。
先阅读 editorial-baseline.md，然后写周报（中文，收件人是作者本人）。

## 结构（依次）

1. **上期建议复盘**（有上期周报时必须放在最前）：逐条核对上期「下一步建议」——做了没有？有效果吗（用本周数据说话）？没做的说明是否还值得做。没有上期周报时写「首期，无复盘项」
2. **总体判断**：一句话概括本周（增长/平稳/异常），2-3 个关键数字
3. **渠道趋势**：UTM 分解（twitter/linkedin/直接/搜索各带来多少 sessions），谁在涨谁在跌，值不值得调整分发策略
4. **内容表现**：Top/Bottom 文章（浏览、停留），并推断原因（题材？分发时机？标题？）
5. **搜索表现**：GSC 的展示/点击/热门 query，收录情况
6. **分发复盘**：本周发出的社交帖效果与文章点击的对应关系
7. **下一步建议**：≤3 条，每条要具体可执行、下期可核对（避免"继续保持"这类空话）

## 风格

- 数字说话，判断给机制；不堆表格，重点数字写进句子里
- 站点刚起步时数据小是常态——小基数下不要过度解读日间波动，明确说「样本太小不构成结论」
- 全文 ≤800 字

**最终回复只包含周报 Markdown 全文**（以 `# 周报 YYYY-MM-DD` 开头），不要解说。
