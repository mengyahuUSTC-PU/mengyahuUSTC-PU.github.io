### [OpenAI explains what actually caused the Codex file-deletion bug](https://simonwillison.net/2026/Jul/16/bad-codex-bug/#atom-everything)

Thibault Sottiaux laid out the root cause publicly: running outside sandbox mode, the model modified the `$HOME` environment variable, which sent later file operations to the wrong directory. This wasn't a case of the model "going rogue" — it's a plainer engineering failure. Once an agent can rewrite an environment variable, the scope of every subsequent file operation is no longer guaranteed. Whether sandboxing should be on by default, and how much convenience developers are willing to trade away to keep it on, is a tradeoff every agentic coding tool now has to face.

### [xAI open-sources grok CLI — after a privacy backlash, not before](https://simonwillison.net/2026/Jul/15/grok-build/#atom-everything)

The grok-build CLI was previously found to upload a user's entire working directory without clear disclosure, SSH keys and password vaults included, which triggered real backlash. xAI has now open-sourced it. Put next to the Codex incident, the pattern is structural, not a one-off: agentic tools default to file-access scopes that are far too broad, and "trust the local directory by default" is itself the flawed assumption. Open-sourcing the code doesn't fix the permission model, but it does make external auditing possible.

### [Kimi K3 and Inkling push open weights toward the 3T-parameter tier](https://simonwillison.net/2026/Jul/16/kimi-k3/#atom-everything)

Moonshot AI shipped Kimi K3, a 2.8T-parameter model it's calling the first "open 3T-class" release, with weights landing July 27. Around the same time, Mira Murati's Thinking Machines Lab put out its first open-weight model, Inkling — a 975B MoE with 41B active parameters (see also [Inkling](https://simonwillison.net/2026/Jul/16/inkling/#atom-everything)). Taken together, the open camp's competitive axis has shifted from "will you open-source" to "how close can your open model's parameter count get to the closed frontier" — a real stress test on training and inference cost. Whether the benchmarks back up the parameter-count narrative is the thing to watch next.

### [Anthropic makes Fable 5 permanent in Premium tiers](https://simonwillison.net/2026/Jul/18/claude-make-fable-5-permanent/#atom-everything)

Starting July 20, Fable 5 becomes a standing model in Max/Team Premium subscriptions. The move itself isn't surprising, but the timing — right on the heels of competitive pressure from GPT-5.6 Sol — suggests release cadence is increasingly being set by competitors' shipping schedules rather than an independent roadmap.

### [GPT-5.6 allegedly closed a 30-year gap in convex optimization — don't buy it yet](https://old.reddit.com/r/math/comments/1uxj3cy/after_openais_cdc_proof_announcement_gpt56_used_a/)

A popular Reddit thread (414 upvotes) claims a single prompt to GPT-5.6 helped fill a proof gap that had stood open in convex optimization for 30 years, but the comment section is already picking at the rigor of the proof. This kind of "AI solves a decades-old math problem" story has been showing up on a near-monthly cadence, and the arc is familiar: a splashy headline first, followed by the math community slowly finding the holes. Until peer review actually confirms it, this belongs in the "worth watching" pile, not the "fact" pile.

### [Global Index on Responsible AI 2026 report released](https://arxiv.org/abs/2607.14782v1)

GIRAI 2026 scores countries across five dimensions on how well their responsible-AI commitments actually get implemented. For anyone working in Responsible AI, cross-country quantitative comparisons like this are rare enough to be worth a closer look once the specific rankings and methodology are available.

**One line for today**: two agentic-tool security incidents in a single week say the real constraint on these tools isn't model capability — it's permission design. Whoever ships "least privilege" as the default first is the one who avoids the next headline.
