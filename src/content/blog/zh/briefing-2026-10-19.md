### [开源编程 agent OpenCode 平台被入侵，用户 API key 被盗刷](https://techcrunch.com/2026/10/19/hackers-hit-ai-coding-tool-opencode-running-up-charges-on-users-ai-accounts/)

10 月 16 日夜间，攻击者进入 OpenCode 一个待退役的旧系统，拿走了部分用户存在 OpenCode Console 里的 OpenAI、Anthropic、Google API key：约 1.4% 的 Console 用户受影响，有人被刷掉数百到约 1700 美元。Anthropic 和 Google 封禁了他们认为已泄露的 key，OpenAI 则帮受影响用户恢复了访问并退了款；开源 CLI 本体不受影响，官方公开声明仅发在 X，但受影响用户收到了邮件通知（另见 [The Hacker News](https://thehackernews.com/2026/10/opencode-console-breach-may-have.html)）。OpenCode 把这次事件定性为「大规模蒸馏攻击」，即偷 key 批量抓取模型输出、拿去训练别家模型，但这个说法还没有独立证据支持。最值得记住的细节来自联合创始人 Dax Raad：排查时团队用的前沿模型一读到恶意载荷就触发安全过滤、拒绝分析，直到拿到 OpenAI 的 Daybreak Blue 通道（通过审核的用户可使用更少拒绝防御性安全工作的模型）才顺畅起来。安全过滤分不清攻击者和防御者，这次有了直接拖慢事故响应的实例。

### [微软安全博客：把企业里的 AI agent 当「内部人」来管](https://www.microsoft.com/en-us/security/blog/2026/10/19/agents-are-your-newest-insiders-security-must-move-at-their-speed/)

微软 10 月 19 日发文提出，agent 是企业新的 insider：有数据和系统权限、以机器速度行动、可能被操纵或偏离意图，并推出 Guardian Agents 等一组产品，给 agent 做持续风险评分、按风险动态收紧权限（可降权或隔离，不止允许/拒绝两档），可识别包括 Claude Code、GitHub Copilot 在内的 60 种本地 agent。Satya Nadella 的表述值得原文记录：「最值得信任的 agent 系统，不是模型最可信的那个，而是设计上让我们最不需要信任模型的那个。」把零信任架构从员工搬到 agent，正在从安全圈共识变成大厂产品线。（另见 [TechCrunch](https://techcrunch.com/2026/10/19/microsoft-says-ai-agents-are-like-insider-threats-as-frontier-models-cant-be-trusted/)）

### [Bloomberg：Nscale 与 Anthropic 再谈一笔 450 亿美元算力交易](https://www.bloomberg.com/news/articles/2026-10-19/nscale-anthropic-in-talks-for-45-billion-cloud-computing-deal)

继 8 月那笔约 450 亿美元的协议后，据 Bloomberg 报道，两家正在谈第二笔同等规模的交易：西弗吉尼亚 Monarch 园区的第二栋楼、460 兆瓦、用 NVIDIA Vera Rubin 芯片，Anthropic 还握有第三栋楼的优先权；知情人提醒谈判未最终敲定，细节可能变化。同一客户在同一园区连下两笔同量级长约，而且双方都在走向 IPO：Nscale [已于 9 月申请在纽交所上市](https://www.cnbc.com/2026/09/18/nscale-ai-cloud-provider-ipo-nscl.html)，Anthropic [6 月已向 SEC 秘密递交 S-1 草案](https://www.anthropic.com/news/confidential-draft-s1-sec)，这类合同既是算力采购，也是写进招股书的增长叙事。

### [MiniMax 发布 M3.1 Flash：主打 agent 成本砍 70%](https://www.minimax.io/blog/minimax-m31f)

MiniMax 称新模型推理速度提至近 3 倍、使用成本降 70%，定价每百万 input token 0.15 美元、output 0.60 美元，并承诺后续开放权重；它此前以「Space Bunny」为代号匿名公测（发布前不挂厂商名、在第三方平台上线测试），处理了超过 200 万亿 token。基准选择里有个信号：网络安全被当成卖点之一，漏洞发现基准 CyberGym 拿到 82%。agent 会成倍放大推理用量（NVIDIA [估计多 agent 工作流产生的 token 量最高可达普通对话的 15 倍](https://blogs.nvidia.com/blog/nemotron-3-super-agentic-ai/)），单位成本正在成为中国厂商最一致的竞争点。

### [Jack Clark 对 IMF 演讲：他认为「奇点」已经开始](https://jack-clark.net/2026/10/19/import-ai-477-in-which-i-tell-the-imf-the-singularity-has-begun/)

Anthropic 联合创始人 Jack Clark 在 IMF 曼谷会议上说，AI 已在多个学科同时加速科学发现，举的证据包括 Humanity's Last Exam 得分从 2025 年 1 月的 8% 涨到 67.7%、FrontierMath 从 2% 到 94%，并给出美国 GDP 2030 年达 44 万亿美元的情景测算。把基准曲线外推到 GDP 应当打折扣，但更值得看的是受众：一位前沿实验室创始人在向财政与宏观机构铺垫，让它们提前把 AI 写进增长模型。

### [研究：验证码求解器现在「见一两次就学会」](https://arxiv.org/abs/2609.02393)

这篇论文把 YOLOv8 检测器和开源视觉语言模型组合起来，只靠截图和模拟键鼠输入（不碰浏览器内部接口）就在 16 类 CAPTCHA 上拿到 85.4% 准确率；关键机制是 VLM 的每个答案自动变成检测器的训练标签，新题型出现一两次就被纳入，检测器被运营方扰动图片打垮后，还能靠 VLM 的标注恢复。论文模拟了一年攻防，防守方每月更新一次，求解器每轮都恢复了。验证码的安全假设是「被拦住的 bot 会一直被拦住」，对会自我标注的求解器，这个假设已经不成立。

### [Ask HN 热帖：上线了自己看不懂的 AI 代码，怎么办](https://news.ycombinator.com/item?id=50151036)

一条 Ask HN 帖子转述了一位 Meta 工程师在 LinkedIn 上的发言，引来数百条评论：这位工程师说，AI 写码的速度让逐行审查不再可能，自己对系统只剩架构级理解；帖子里的主流回答是设计必须由人定、AI 只负责实现，再用测试兜底验证。和 OpenCode 事件放在同一天看有些讽刺：一边是开发者上线自己没读懂的代码，一边是防御者想读懂恶意代码却被安全过滤拦住。「理解」的单位正在从代码行上移到设计与接口，但相应的责任规范还没跟上。

### [NVIDIA 与欧洲广播联盟把「主权 AI」框架扩到内容生产](https://blogs.nvidia.com/blog/media-agentic-security-european-public-service-broadcasting-global-content-production/)

NVIDIA 与 EBU 扩展合作，给欧洲公共广播机构提供部署 AI agent 的参考架构：Nemotron 开源模型、敏感编辑内容本地处理（接 Microsoft 主权云与 Nebius 的欧洲算力），并明确工作负载在哪跑、数据归谁管。对公共媒体来说，卖点在编辑独立性：通过合同约定敏感材料在哪里处理、受谁的司法管辖，尽管技术栈仍跑在合作方的云上。「主权 AI」正从政府口号变成行业采购的具体规格。

## 研究速递

### [HexaShell：极简 harness 让 VLM agent 变成机器人控制器](https://arxiv.org/abs/2610.23479)

harness 只做一件事：把 agent 的命令翻译成机器人动作；GPT-6-Astra 看三路相机画面、失败后读日志、自己写小工具程序修正，在 RoboDojo 的 42 个任务上拿到 39.7% 成功率，是该基准目前最好成绩，可与专门训练的操作策略相比。失效边界画得很清楚：推挤类任务成功率 92.5%，紧配合插入只有 8.3%，瓶颈出在接触阶段的力控，推理层面反而不是短板。做机器人学习的研究者值得点进去：它实测了「coding agent 能把物理世界控制到什么程度」。

### [GPT-6-Astra 算不算有了具身智能？](https://arxiv.org/abs/2610.22471)

论文用统一协议在 12 个具身基准、8 种真实机器人配置上做了大规模评测，结论是模型「跨过了具身能力的门槛，但还没跨过实用具身智能的门槛」：基准分数强，但真机部署时演示数据的采集成本、执行时间与成功率的取舍都还不实用。对仍在「每个任务单独建模」的机器人团队，这篇给出了通用模型路线目前能走到哪一步的实测坐标。

### [LiveMACE：用真实金融市场做 agent 的过程级评测](https://arxiv.org/abs/2610.09872)

五个前沿模型在真实市场连续运行 30 天，评测不只看收益，还审完整决策轨迹，对工具使用、持久记忆、规则遵循、多 agent 协作分别诊断。核心发现是「结果与能力的落差」：相近的收益可能来自质量完全不同的决策过程，只看收益排行榜会把运气误当能力。做金融类 agent 评测的研究者可以直接借用这套设计。

**今日一句话**：agent 时代的安全攻防正在向模型周边的配套层集中：存 key 的 console、agent 手里的权限。OpenCode 事故、微软的 Guardian Agents、OpenAI 的 Daybreak Blue，指向的都是同一个地方。
