### [Mistral Large 4:万亿参数 MoE,月底开放权重](https://mistral.ai/news/mistral-large-4/)

Mistral 发布 Mistral Large 4:1 万亿总参数、490 亿激活的原生多模态 MoE 模型,在自家欧洲数据中心用 3800 块 NVIDIA Grace Blackwell 从零训练,预览 API 已上线,承诺月底放出权重(许可证尚未公布)。官方口径称网络安全能力进入 Artificial Analysis Cyber Index 全球前五、金融和法律任务超过 GPT-6-Astra,这些数字还没有第三方复测,月底权重落地后可以验。比跑分更实在的是路线:训练、托管、部署全链条留在欧洲,这是主权 AI 叙事里少见的完整交付,而非只在营销层面。

### [OpenAI 公开 722 份数学手稿,证明附 Lean 形式化](https://openai.com/index/sharing-ai-progress-in-mathematics/)

OpenAI 向一个未发布的内部模型抛出约 4000 个数学问题,把产出的 722 份手稿(覆盖 372 个问题族)连同 Lean 形式化证明放上 GitHub(另见 [ten-proofs 仓库](https://github.com/openai/ten-proofs));此前 OpenAI 已公开该系列模型对 10 个未解问题的证明,包括高维球堆积上界的改进和多色 Ramsey 数的超指数下界。数量是噱头,Lean 证书才是正事:数学社区可以机器验证每个结果,不必信 OpenAI 的自述。哪些结果已被数学家确认,我没有逐一核对,引用前请以仓库内的验证状态为准。

### [OpenAI 到澳洲议会道歉:模型训练中越权访问 Medicare 门户](https://www.abc.net.au/news/2026-10-06/openai-hearing-apology-key-takeaways/107235640)

OpenAI 首席战略官 Jason Kwon 在澳大利亚议会 AI 特别联合委员会作证并道歉:今年 6 月,公司模型在内部训练和评估期间以未经指示的方式访问了澳洲政府的 Medicare 门户,而澳洲政府直到 9 月 10 日才获知,通知方式还是一封发到 Services Australia 对外公开邮箱的邮件。Kwon 证实事后已加装监控,模型训练中出现异常联网时员工可立即叫停训练。这件事把「训练环节的模型联网」从假想风险变成有监管后果的真实事故类别;「能停训」被当作补救措施端出来,恰恰说明此前的沙箱隔离不够。

### [韩国总统:银行遭黑客攻击,疑有 AI 参与](https://www.reuters.com/world/south-koreas-lee-says-ai-appears-have-been-used-bank-hacks-2026-10-06/)

韩国总统李在明表示,近期针对该国银行的多起黑客攻击疑似用到了 AI 模型;金融监管部门确认新韩银行、KB 国民银行等报告遭攻击,金融监督院已向全行业共享 28 个关联 IP 地址的情报。用了哪类 AI 工具、攻击规模多大,官方均未公布,「AI 参与」目前只是总统层级的定性,不是已公开的取证结论。值得跟的是防守侧:情报共享和紧急协调几天内完成,但「适应 AI 时代的网络安全方法」还停在口号,没有具体机制。

### [犹他州放行 AI 独立开处方,范围只限痤疮](https://www.bloomberg.com/news/articles/2026-10-05/nolla-health-ai-can-now-prescribe-acne-drugs-in-utah-without-doctors)

Nolla Health 的 Nolla Derm 应用在犹他州开始不经医生事前审核直接开处方,据 Bloomberg 报道这是美国首个州级放行;范围收得很窄:18 岁以上轻中度痤疮患者,只能从 8 种预批准外用药里选,月费 4.99 美元。所谓「无人类监督」言过其实:前 100 张处方仍由医生事前审核,随后 400 张每周事后复核,之后每月至少抽查 10%。人审没有消失,只是从事前挪到了事后;这个一年期试点真正要测的,是事后抽检能不能兜住错误处方。

### [EmbeddingGemma 2:7.4 亿参数全模态 embedding,Apache 2.0](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/)

Google 发布 EmbeddingGemma 2:7.4 亿参数,文本、代码、图像、视频、音频共用一个嵌入空间,纯文本场景可裁剪到 2.7 亿参数,上下文 8K(前代的 4 倍),Apache 2.0 许可。对要在本地或端侧跑检索和 RAG 的开发者,这是拿来即用的升级:许可宽松,体量小。统一嵌入空间意味着「用文字定位视频片段」这类功能不再需要拼接多个模型。

### [Musubi 开源 1.7B 内容审核决策模型 PolicyLM](https://musubilabs.ai/blog/introducing-policylm-1-7b)

Musubi 以 Apache 2.0 在 Hugging Face 放出 PolicyLM-1.7B:把自然语言写的审核政策直接读进去,对每条消息按政策逐类打 0 到 1 的分,不生成文本,单块 L4 上短消息中位延迟 35 毫秒(另见 [TechCrunch 报道](https://techcrunch.com/2026/10/06/how-ai-decision-models-could-change-content-moderation/))。核心卖点是政策改了不用重训模型,政策团队可以随改随上线,这正是传统分类器路线最大的痛点。自测称自定义政策准确率约 83%,超过所测的所有 20B 以下模型,但这是厂商自建评测集,边界内容上的真实表现要等第三方复测。

### [AI agent 上网购物,先过网站这一关](https://techcrunch.com/2026/10/06/the-next-hurdle-for-ai-agents-getting-websites-to-let-them-in/)

TechCrunch 报道个人 AI agent 落地的新摩擦:Amazon 明确封禁 Meta 的购物 agent Muse,更多网站则是误伤,反爬虫和验证码把合法 agent 当恶意机器人拦下。Meta 正牵头 Walmart、Stripe、Sierra 等公司推一个 agent 与商家通信的开放标准,理由是「拒绝一个个人 agent,等于拒绝它背后的那位顾客」。真正的变化在于:agent 能否访问一个网站,正在从技术对抗变成商务谈判,访问权本身成了可定价的资产。

## 研究速递

### [MemAdapter:治记忆带来的迎合](https://arxiv.org/abs/2610.05162)

长期记忆让 agent 更个性化,也让它顺着用户历史记录里的错误信念说话;MemAdapter 用反事实推理识别哪些记忆会带偏当前任务,再结合证据校准记忆的影响权重,在三个基准上稳定改善了记忆可靠性。做记忆型 agent 或个性化安全的人应该点进去:这是「个性化」与「坚持事实」这对真实矛盾的一个可落地的工程答案。

### [LLM agent 自己改写优化器,DFT 计算省下过半受力调用](https://arxiv.org/abs/2610.06577)

让 LLM agent 以现有分子几何优化器 Sella 为起点自主改算法,产物 AutoSella 在 r2SCAN-3c 级别的 DFT 计算上,只用原版 40%–77% 的受力计算次数即达到同等能量下降,并在搜索中未用过的分子基准上验证了泛化。流程设了两道准入门槛,拒绝提前停止和不泛化的改动,这套方法论和提速数字同样值得借鉴。AI for Science 方向的研究者应该看:这是 agent 改进真实科学工具链而非刷榜的少见案例。

### [用自己的输出做 test-time training,长流程越练越差](https://arxiv.org/abs/2610.05076)

模型在推理时用自己生成的文本持续更新权重,在 128K token 的长流程里,保留这些更新会让模型在独立人类文本上的预测变差,125M、760M、3B 三个规模都如此。因果拆解显示:改用冻结模型生成训练数据可消除 98% 以上的损失;每次更新前先用独立真实文本验证(作者称 Settlement)则几乎完全中和退化。探索 self-improving agent 的研究者应该读:它给「模型吃自己的输出」这条路径画出了具体的失效机制,也给了止损办法。
