8 月 14 日，Z.ai（智谱）发布 [GLM-5.3](https://z.ai/blog/glm-5.3)。官方公告里最扎眼的一句话不在成绩单里：所有提升都来自扩大后训练，「更多任务环境、更多环境类型、更长的训练」。基座还是 GLM-5.2 那个 7430 亿参数的模型，一个参数没动（[官方公告](https://x.com/Zai_org/status/2088132965922476159)）。

成绩单本身也够看：按 Z.ai 公布的数字，在以真实软件漏洞为素材的安全评测 CyberGym 上，GLM-5.3 拿到 84.5%，高于 Claude Mythos 5 的 83.8% 和 GPT-5.6 Sol 的 83.6%；在让模型于命令行终端里完成真实工程任务的 Terminal-Bench 3.0 上，从上一版的 4.6 涨到 28.3。权重文件约两周后开放下载。

过去两年，解释「中国模型为什么追得这么快」，市面上最流行的答案是一个词：蒸馏。意思是调用美国前沿模型的 API，把强模型的回答攒成数据集，拿去教自己的模型模仿。便宜，快，也符合「跟随者抄近道」的直觉。Nathan Lambert 这次在 [Interconnects 上发文](https://www.interconnects.ai/p/glm-53-how-chinese-labs-keep-stride)直接否定了这个解释。我把他的分析和官方材料对了一遍，认为他是对的，而且这件事比「是不是蒸馏」本身重要。

## 蒸馏论为什么这次失效

先交代常规做法。一个大模型的训练分两段：预训练用海量文本教模型语言和知识，吃掉绝大部分算力；后训练在这个基座上教模型「干活」，包括指令微调和强化学习，通常只是收尾环节。常规的版本升级两段都要动。GLM-5.3 只动了后一段，并且把这一段扩到了反常的规模。

蒸馏的原料是文本：你能拿到的只是对手模型输出的答案。这能教会模型「说得像」，教不会模型在真实环境里把活干成。因为后训练里的强化学习要的不是示范文本，是环境。Z.ai 官方举的例子很具体：把模型放进一个机器学习基础设施工程师的工作台，能访问计算集群、内部文档、代码库和实验结果，让它真的做任务，按结果打分。这样的环境是一套工程资产，要有人搭沙盒、造任务、写评分逻辑，它不会通过 API 泄漏出去。Lambert 的原话是：强化学习环境、基础设施、训练算法，这些东西蒸馏不来。

## 真正起作用的是什么

Lambert 列了六条机制，按我的理解可以归成三层。

**第一层是发布节奏的时间差。** 他认为这是最大的单一因素：美国前沿实验室从模型训练完成到公开发布，中间隔着数月的内部评估和安全测试；中国实验室把这个间隔压到以天和周计。于是每一次公开对比，实际上都是「刚出炉的中国模型」对「几个月前就练完的美国模型」。这意味着一部分「追平」是两张不同时刻拍的照片放在一起比，也意味着前沿实验室手里始终有比你看到的更强的东西。

**第二层是窄目标加上直接的经济刺激。** GLM-5.3 聚焦编码和智能体任务（指模型自主多步调用工具完成工作）。Lambert 推测它的覆盖面比 Claude、GPT 窄，可能只支持文本、没有视觉输入，这一点他自己标注为推测，我也没能在官方材料里找到对模态的说明。窄有窄的好处：后训练算力可以全部押在可测的能力面上。刺激也直接：Z.ai 今年 1 月在港股上市，[Bloomberg 7 月报道](https://www.bloomberg.com/news/articles/2026-07-17/z-ai-set-to-be-first-china-ai-firm-with-1-billion-annual-sales)其年化收入达到 10 亿美元，公开评测成绩连着股价和融资，这比 OpenAI、Anthropic 面对的压力传导链短得多。不过 Lambert 也专门说明，GLM-5.3 并非刷榜过拟合，各家在扩展强化学习时撞的墙是类似的。同一份成绩单里也有反例：漏洞利用评测 ExploitBench 上 GLM-5.3 是 54.4%，离 Mythos 5 的 78.0% 还有相当距离。追平不是全面的。

**第三层是环境产业和组织效率。** 真正坐在「蒸馏」传闻那个位置上的机制，其实是一个新兴市场：据 Lambert 转述，美国数据公司在向中国实验室出售强化学习环境，随后这些实验室更快地发布了下游模型。他自己注明这条的不确定性还很大，我也没有找到独立信源，此处待核实。但值得分辨的是它和蒸馏的区别：买家拿到的是训练基础设施本身，蒸馏拿到的只是输出文本，前者是合规的商业交易，出口管制和 API 封锁都拦不住。组织层面，Z.ai 出身清华 THUDM 团队，Lambert 判断其算力使用效率和人才密度不输美国前沿实验室。

那么选题问的「架构差异」呢？答案是这一轮增量和架构选择无关，基座没动就是明证。而且中国实验室在架构上走的也不是模仿路线：Moonshot 上个月开放权重的 [Kimi K3](https://huggingface.co/moonshotai/Kimi-K3) 是 2.8 万亿参数的混合专家模型，用自研的 Kimi Delta Attention 注意力机制，原生多模态；GLM-5.3 的参数量只有它的四分之一左右，纯走后训练路线。两家路线分叉成这样，说明没有一个共同的「老师」在被抄。

## 对「开源能否持续追平前沿」意味着什么

先把词说准。GLM-5.3 和 Kimi K3 都是开放权重，严格说不是开源：权重文件公开，谁都能下载后在自己的机器上部署，但训练数据、训练代码，以及上面说的那些强化学习环境，都不公开。最难复制的部分恰恰是不公开的部分。

我的判断分两半。能力上，「追平」要打引号：追平的是可测、可环境化的窄能力面，编码、终端任务、漏洞分析；再算上发布时间差，前沿实验室始终握着未发布的余量。但趋势上我同意 Lambert 的结论：能力扩散只是时间问题，他的原话是「何时，而非是否」。就算某一家把权重扣下不放，别家也会放出来。

最后落到我最关心的一点。GLM-5.3 这次在 CyberGym 上的分数超过了公布对比的所有闭源前沿模型，而它的权重两周后就能下载。Z.ai 自己做了克制：先开放 API，权重推迟发布，中间留给安全评估和加固。但开放权重意味着部署侧的防护是可拆的：下载者在自己的机器上跑模型，厂商的分类器和监控就都不在了。单个公司的克制，管不住整个行业的扩散速度。Lambert 因此呼吁行业联盟或政府层面的协调，方向我认同，可执行的机制目前还看不到。

「中国模型靠蒸馏」这个解释真正的害处，是它暗示只要断掉 API 访问就能断掉追赶。GLM-5.3 演示的路径里，环境工程、发布节奏、组织效率，没有一样是封锁能拦住的。把这一点看清，比继续争论「是不是蒸馏」有用得多。
